## Adding an app

1. Create a folder named after the app, e.g. `myapp/`.
2. Copy `_templates/privacy.md` to `myapp/privacy.md` and replace `APP_NAME`, `APP_SLUG` and `DATE`.
3. Add an `index.md` describing the app, and a row to the table in `index.md` and above.
4. Push to `main`; the pages are live within a minute or two.

When a policy changes, update the date at the top and the copy shown inside the app together.
